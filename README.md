# Odd or Even Program

This repository contains a simple Python program to check whether a given number is odd or even.

## Logic of the Code
The logic of the code is straightforward:
1. The function `check_odd_even` takes an integer as input.
2. It checks if the number is divisible by 2 using the modulus operator (%).
3. If the result is 0, the number is even; otherwise, it is odd.
4. The program prompts the user to input a number and displays whether it is odd or even.

## Example
- Input: `4`
- Output: `The number 4 is Even.`
